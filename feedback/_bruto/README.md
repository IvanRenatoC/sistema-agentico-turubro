# `_bruto/` — bandeja de entrada del feedback

Lo que llega sin procesar: notas al pasar, capturas de un mensaje, un audio después de una reunión,
el correo donde el cliente reclama.

**Es zona de paso.** Se deja acá para no perderlo, y se destila a `GLOBAL.md`,
`feedback/staff/<id>.md` o `feedback/packs/<id>.md`, donde el sistema lo va a leer. **Nadie lee
esta carpeta durante una corrida.**

## Cómo se usa

1. Deja el material con la fecha en el nombre: `<AAAA-MM-DD>-<de-qué-se-trata>.<ext>`
2. Cuando destiles, anota en el archivo de destino de dónde salió.
3. Borra o archiva lo ya destilado. Una bandeja que solo crece deja de mirarse.

Si el material contiene datos del cliente, aplica lo mismo que al resto del repositorio: revisa el
bloque de confidencialidad de `CLAUDE.md` antes de dejarlo versionado.
